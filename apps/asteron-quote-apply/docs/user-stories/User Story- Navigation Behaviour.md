# User Story: Navigation Behaviour

| Story card | URE Behaviour |
| --- | --- |
| JIRA |   |
| User Story | As anAsteron Adviser/Adviser staff, I want to go to previous pages so that I can update the details if needed. |
| Pre-Conditions |  |
| PC01 |  URE Questionnaire completed |
| Acceptance Criteria |  |
|  AC01 | **Given** I am an Adviser/Adviser staff**When** URE personal questionnaire completed **Then** I should be able to see completed tick mark in the navigation panel. |
|  AC02 | **Given** AC01 is active**When** I change answer to a question in the underwriting questionnaire that results in further questions being asked**Then** completion tick should disappear. |
|  AC03 | **Given** AC01 is active**When** I want to update any of the previous pages **And **click those pages**Then** I should be redirected to corresponding page **And **I should be able to see completion tick. |
|  AC04 | **Given** AC03 is active**When** I have successfully update any of the details in section 3 or  4**And** I click next **Then** section 5 and onwards should no longer be ticked(completion tick should disappear). |
