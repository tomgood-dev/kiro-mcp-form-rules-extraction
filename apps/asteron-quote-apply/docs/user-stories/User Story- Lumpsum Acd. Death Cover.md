| --- | --- | --- |
| JIRA |   |  |
| User Story | As an Adviser/Adviser StaffI want to be able to apply for lump sum cover while I am creating a quote for a client So that I am able to add various lumpsum covers to the clients policy. |  |
| Pre-Conditions |  |  |
| PC01 | Adviser has been on-boarded (training completed, credentials provided to Adviser) |  |
| PC02 |  |  |
| Acceptance Criteria |  |  |
|  AC01 | **Given** I am anAdviser or an Adviser staff **When** I am “creating a new quote” **Then** I should be provided the ability to apply for ‘lumpsum cover’ in the quote |  |
|  AC02 | **Given **I am in the Lump Sum Cover section**When **I am creating a new business quote/application**Then **I am able to see below lump sum covers - Life - TPD - Trauma - Cancer - Acd. Death - Needlestick - Specific Injury  **And **I must be able to select 1 or more covers |  |
|  AC03 | Given I am in the lump sum cover section of the New Business Quoting toolWhen I select Acd. DeathThen I must be provided the ability to enter the Sum Insured amountAnd Premium structure should be greyed out and set to Stepped |  |
| AC04 | **Given **I have selected **Acd Death****When **age next birthday is more than 70**Then **an error message “The maximum Age Next Birthday for Accidental Death Cover is 70” should be displayed |  |
|  AC05 | **Given **I have selected **Acd Death****When **age next birthday is less than 17**Then **an error message “The minimum Age Next Birthday for Accidental Death Cover is 17” should be displayed |  |
| AC06 | **Given **I have selected **Acd Death**,**When **Sum Insured is more than 1,000,000**Then **an error message “The maximum sum insured for Accidental Death Cover is $1,000,000.” should be displayed |  |
|  AC07 | **When **I have selected the cover type**Then **I must be provided the option to ‘add’ or ‘remove’ the cover type or modify details**And **I must be able to view the changes to the premiums on the “Progress Panel for application progress” |  |
|  AC08 | **Given** I am in the *Acd Death* section of the *New Business Quoting Tool*, **When** I click the **"?" icon** next to any label, **Then** the system must: - Display the **corresponding tooltip** with relevant information for that label. **Label****Tooltip**Sum InsuredThe large sum insured discount bands for Accidental Death are: - $150,000 - $249,999 - $250,000 - $499,999 - $500,000 - $999,999 - $1,000,000   |  |
| **Label** | **Tooltip** |  |
| Sum Insured | The large sum insured discount bands for Accidental Death are: - $150,000 - $249,999 - $250,000 - $499,999 - $500,000 - $999,999 - $1,000,000   |  |
| Business Rules | The maximum Sum Insured for Accidental Death Cover, is $1,000,000 |  |
