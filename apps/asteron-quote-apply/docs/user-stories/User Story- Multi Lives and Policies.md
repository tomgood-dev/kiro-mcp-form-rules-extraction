| User Story | As an Adviser/Adviser StaffI want to be able to add an additional life insured when I am applying for a new business quote/application So that I am able to get quote for multiple lives the same time. |
| Pre-Conditions |  |
| PC01 | Adviser has been on-boarded (training completed, credentials provided to Adviser) |
| PC02 |  |
| **Dependencies: User Story** | [User Story: Create a New Business Quote](https://acendalife.atlassian.net/wiki/spaces/CFDDP/pages/1058472042/User+Story+Create+a+New+Business+Quote) |
| Acceptance Criteria |  |
|  AC01 | **Given** I am anAdviser or a Adviser staff **When** I apply for a new quote/application**Then** I should be able to ‘add a life’ to the quote/application |
|  AC02 | **Given** I have selected ‘add a life’  by clicking “+Life” button**When** creating a new business quote/application**Then** I should be able to capture the following information: - Personal Details of the client     - First Name      - Second Name      - Date of birth (dd/mm/yyyy)     - Age next birthday (Mandatory and must be between 11 and 75)     - Gender (Mandatory)     - Smoker (Mandatory)     - Occupation (drop down list)     - Occupation code (drop down list - This should be auto populated upon selecting occupation)     - Employment status (drop down list)     - Annual Income     - Inflation adjustment benefit      - Premium freeze       - We pay your premiums (drop down list)     - Flexi Rate (drop down list)  - Lumpsum Cover     - Life      - TPD     - Trauma     - Cancer      - Accidental Death     - Needlestick     - Specific Injury - Disability Cover      - Mortgage & Living      - Income Protection      - Workability - Kids Cover |
| AC03 | **Given** the user is on the quote entry screen**When** the user clicks on "+Life" without entering any required details, or attempts to navigate to "Life 1" prematurely**Then** the system must display the following error message: *“Please enter the minimum requirements for a quote before proceeding to another life.”* |
| AC04 | **Given** AC03**When** the user clicks on "+Life" or navigates to "Life 1"**And** the user has entered the minimum required details (age, gender, and smoker status)**Then** the system must allow entry of new life insured details or successfully navigate to "Life 1" |
| AC05 | **Given** I am on the quote screen**When** I have added multiple lives to the quote**Then** the system should display the total yearly premium for each life in the right-hand panel |
|  AC06 | **Given** multiple lives have been added to the current quote**When** the user clicks the “X” icon on a life tab**Then** a confirmation pop-up should appear with the message: *“Are you sure you want to delete this life?”***And** the pop-up should present two options: **Cancel** and **Delete** |
| AC07 | **Given** AC06**When** I click **Cancel****Then** I must be redirected to the quote screen without deleting the life |
| AC08 | **Given** AC06**When** I click **Delete****Then** I must be redirected to the quote screen **And** selected life and associated policies should be deleted in both quote and right-side panel |
|  AC09 | **Given** I have added multiple lives**When** I click **Apply Now****And **minimum premium is \< 0 for any of the lives**Then** an error message “The minimum premium is $240.00 per year per Life insured” should be displayed |
|  AC10 | **Given** I have added multiple lives to the quote**When** I click the **Apply Now** button**And** the minimum premium is **greater than or equal to $240 per life****Then** I should be redirected to the **Client Summary** page**And** for each life, the following fields should be displayed: 1. **First Name** – prepopulated and editable 2. **Middle Name** – empty text box 3. **Last Name** – prepopulated and editable 4. **Date of Birth** – prepopulated if entered on the quote screen, and editable 5. **Proceed to Application** button |
| AC11 | **Given** AC10**When** I click Proceed to Application button on Life 1 **Then  **system must proceed with application only for Life 1 |
| AC12 | **Given** AC11**When** I have submitted Application for Life 1 **Then  **Proceed to Application button should be greyed out for Life1 **and **I****must proceed with application for other lives other than Life 1 |
| AC13 | **Given** I have already added **10 lives** to the current quote**When** I attempt to add an **11th life****Then** the **“+Life”** button should be **disabled****And** I should **not** be able to add any additional lives to the quote |
| AC14 | **Given** I am in the quote screen**When** I click **“+ Personal Policy”**   button**Then** I should be presented with below fields or options in the new tab  - Inflation adjustment benefit  - Premium freeze   - We pay your premiums (drop down list) - Flexi Rate (drop down list)  - Lumpsum Cover     - Life      - TPD     - Trauma     - Cancer      - Accidental Death     - Needlestick     - Specific Injury - Disability Cover      - Mortgage & Living      - Income Protection      - Workability - Kids Cover |
| AC15 | **Given** I am in the quote screen**When** I click **“+ Business Policy”**  **Then** I should be presented with below fields or options in the new tab  - Inflation adjustment benefit  - We pay your premiums (drop down list) - Flexi Rate (drop down list)  - Lumpsum Cover     - Life      - TPD     - Trauma     - Specific Injury - Disability Cover      - Business Disability     - Farmers Disability     - Business Expenses |
| AC16 | **Given** I am viewing one or more policy tabs**When** I click the **“X”** icon on a policy tab**Then** that specific policy tab should be **deleted** from the view |
| AC17 | **Given** I have added multiple lives **When** I add multiple covers for each of those policy tabs**Then** I should be able to see below in the right-side panel  - premium breakdown per policy and per cover - Total yearly premium per life - Total premium for all lives |
| AC18 | **Given** I have added multiple lives **When** I add multiple covers for each of those policy tabs**Then** I should be able to navigate to - any life - any policy under that life |
| AC19 | **Given**the user has added **multiple lives** to quote, **When** the user clicks **Apply Now**, **Then** the system must: 1. **Redirect** the user to the **Client Summary** page. 2. **Display one "Start Application" button** for **each Life Insured**. 3. **Show the status** for each individual application. 4. **Allow the user** to **expand or collapse** each Life Insured's section to view or hide details. |
| AC20 | **Given** AC19 is active, **When** the user clicks **Start Application**, **Then** the system must: 1. **Proceed** with the corresponding application process. 2. **Display "Continue Application"** if the user returns to the same screen without submitting the application. 3. **Show the latest status** for each individual application. Examples: If there are two lives in the quote screen and when user clicks apply in quote screen, then for both it should display Pre Application Status. If user progress with first life and submits the same, then in this screen first life should have the status submitted and other should be Pre Application.If there is only single life in the quote screen and user clicks apply in quote screen, then it should display Pre Application Status for single life. |
| AC21 | **Given** AC19 is active, **When** the user submits **one application** and returns to the same screen, **Then** the system must: 1. **Display "Submitted" status** for the application that was submitted. 2. Allow the user to:     - **Download the quote**     - **Download the application**, including all related PDFs:         - Application         - Client Application         - Confirmation         - Declaration     - **Clone the quote** 3. User should be able to proceed with other applications |

| AC26 | **Given** the user has added a policy for a life**And **it has any error message **When** the user attempts to **add new life**, **Then** the system must throw an error message “ Please correct the errors before proceeding to another life” in the pop-up with OK button**And **It should not allow to add another life until they fix errorsExample:Step1: Life 1 and Personal policy has an errorStep2: User tries to add Life 2 |
