| User Story | As an Advisor/Advisor StaffI want to login to Adviser Portal So that I can navigate to new business quote and apply tool |
| Pre-Conditions |  |
| PC01 | A URL link for the adviser portal been created and the URL link to this has been shared with the adviser. |
| PC02 | Adviser logged onto Adviser Portal |
| Acceptance Criteria |  |
| **Scenario: Adviser/Adviser staff are navigating to the URL link to access the online new business quoting tool via their desktop ** |  |
|  AC01 | **Given** I have saved URL link to the New Business Quoting tool in the favourites **When** I click on the URL Link **Then **I am directed to Adviser Portal login screen as quoting tool should be accessed via adviser portal only |
| **Scenario: Adviser/Adviser staff is accessing the New Business Quoting Tool from the Asteron Public website. ** |  |
|  AC02 | **Given **I am a adviser/adviser staff **When **I am logged into the adviser portal**Then **I should be provided the ability to navigate to the New Business Quoting Tool |
|  AC03 | **Given** I have navigated to the Asteron Adviser Portal**When** I have logged onto the portal**Then ** I am able to view and click on the New Business quoting tool **And **I am directed to the New Business Quoting tool UI |
